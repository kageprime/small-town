1 Project Vision & Core Concept

1.1 The Big Idea

NULLSPIRE: LEVEL ZERO is a browser-based roguelike RPG. Ten years after a black mountain outside the fictional city of Cinderfall lit up from inside, 77 floors wait within it. You are Joss Vane, 19, an E-rank porter nicknamed Coffin — every team he carries for loses someone, except him. After his team dies in a double splinter, a sentient parasite called VESTIGE moves into his skull and offers him what no climber gets: levels. Infinite growth, negotiated prices, and an army of bound dead.

1.2 Core Pillars

  • Numbers climb, story costs: roguelike loop — death takes loot + one memory + one echo rank, never levels. Power always, safety never.
  • Every power is priced: HP, Rot, loyalty, memories. No free scaling — the genre contract with the player.
  • Optimal vs quiet: the strongest play and the safest cover are mutually exclusive. The game forces the choice, prices both.
  • Two clocks race: the Gilded Table hunts Joss (2/8), the Returned harvest him (2/6). Growth advances both. Attention accelerates both.
  • Extensibility: floors are data (RunBase + floor packs); echoes are data (roster + loyalty); Wardens are data (accord terms). Act 1 is three runs; the machine runs seventy-seven.

1.3 Target Audience

  • Fans of Solo Leveling / Tower of God power-fantasy progression
  • Roguelike players who want meta-progression with narrative teeth
  • Browser-first players: no install, runs on mid-range hardware
  • Age rating: T (violence, body horror veins, grief — no gore porn)

2.2 High-Level Architecture

  • Boot → GameController: loads config, save (localStorage/IndexedDB), quality preset, then routes to Hub (Terminus Hold) or Run.
  • Two modes, one codebase: Hub mode (Den management: sell, heal echoes, dialogue, Daily Pact, choose run) and Run mode (procedural floor: 3 shuffled zones + 1 fixed story room + VESTIGE twist + boss/extraction).
  • Systems are singletons, content is data: FluxEngine, VestigeSystem, ClockEngine, BindSystem never hardcode floors — floors, echoes, accords load from data packs (mirrors vault structure).
  • EventBus pub/sub for decoupled communication (same pattern as Neon-Lights): clocks subscribe to growth events; UI subscribes to sync/rot; audio subscribes to combat states.

4 Development Conventions & Standards

4.1 Code Style

  • ESLint (Neon-Lights family config); semicolons, single quotes, 100-col soft limit.
  • Classes own state; systems own orchestration; content lives in data packs, never in logic files.
  • Every tunable number lives in constants/ with a comment citing its design source (e.g. // BIND 73% — Table Rules vault note).
  • No magic strings for lore names in code — import from a generated LoreNames.js if needed.

4.2 Class Structure

  • One class per file, file name = class name. Constructor takes a deps object { bus, config, rng } — no globals, no singletons-by-import (GameController wires).
  • Systems expose update(dt) + serialize()/restore() (save support from day one — roguelike meta-progression depends on it).
  • Events over direct calls across modules: bus.emit('growth:level', …) feeds ClockEngine, UI, audio. Direct calls only within a module.

4.3 Memory Management

  • Dispose Three.js geometries/materials on run exit (RunManager owns teardown checklist).
  • Object pools for projectiles, damage numbers, echo summons. No per-frame allocation in hot loops.
  • AssetLoader ref-counts shared assets (Pall cloth, truhound) across runs.

4.4 Performance Rules

  • 60fps desktop / 30fps mobile minimum; quality presets LOW/MEDIUM/HIGH + auto-detect (same approach as Neon-Lights).
  • Run-time procedural generation budgeted: floor compose < 300ms (show a masked transition, never a hitch).
  • Draw-call budget per run zone: < 150 (LOW), < 300 (HIGH). Texture budget: < 256MB.

6 Player Character System

6.1 Character Design

Joss Vane, 19, E-rank porter. Thin, scar-split lip, oversized cutlass, boots he sleeps in. Reads E-rank/11/flat on every scan (VESTIGE eats the overflow). Canon: 01_Characters/Joss Vane.md. Stats: STR/VIT/AGI/INT/WILL/SENSE; +3 points per level; VESTIGE comments on builds.

6.2 Controls

ModeMovePrimarySpecialSystem
HubWASD / left stick / tapE / tap — talk, buy, rest—Esc pause, J journal/clocks
RunWASD / stickClick / tap — cutlass chain1–5 techniques (Gapstep, Bloodwage, Crosspull, Call the Bound, Red Second)Q Whisper log, Tab echo orders, Esc pause

6.3 Camera System

  • Hub: soft-follow third person, shoulder height, terminal crowds part around the player.
  • Run: pulled-back tactical third person; Red Second adds FOV punch + desaturation (3s).
  • Mobile: dynamic zoom-out at low HP (readability over cinema).

6.4 Player State

  • Sync/Rot 0–100: power + control + vein coverage + NPC fear checks. Chaplain mechanics only way down. Endings branch at 40/70/90. Renderer vein-vignette intensity = Sync.
  • Death: revive via parasite; lose run loot + 1 memory (edited, never random) + 1 echo rank-down. Keep levels/XP. SaveManager logs eaten memories (the player can read what was taken — cruelty with UI).
  • Daily Pact: midnight objectives; fail → 4h Penalty Drift preview (playable later; vision-shown in Act 1).

7 NPC & Echo System

7.1 Overview

Two populations: the living (Hub NPCs with schedules + dialogue states) and the Bound (combat echoes with loyalty FSM). Both run through NPCManager/EchoManager. Canon: 01_Characters/, Table Rules.

7.2 Cast Design

7.3 Echo Behaviors (Bound FSM)

  • States: IDLE / FOLLOW / HOLD-DOOR / FIGHT / REFUSE / MOURN (MOURN plays when loyalty drops — the echo relives its death mid-run).
  • Loyalty 0–100 per echo: rises on soul-sand feeding + kept promises; falls on suicidal orders + ignored refusal. Below 30: REFUSE available. At 0: the echo petitions release (a scene, not a stat).
  • Bram (tutorial echo): tank, dry knee jokes, refuses to leave Joss's side even at low loyalty (founding-member exception — documented, not favoritism).

7.4 Truhound Tells

  • Ears up/folded = truth/lie, readable at distance. Barks (double-clipped) whenever VESTIGE speaks — including in the player's own dialogue box. Never explained in dialogue. Tutorialize by placement: one asleep in every lying scene.

7.5 NPC Interactions

  • Hub: talk/buy/rest/ask (ask unlocks codex + quest hooks; asking Beck about the files advances his secret meter).
  • Runs: echoes take orders via Tab radial (Follow / Hold / Strike / Release-request). Orders against an echo's nature cost loyalty visibly.

7.6 VESTIGE Dialogue System

  • Voice: street cant, theatrical, intimate. Line pools per state: wake, level, near-death, deal, lie-glitch, bored, delighted, hungry. (Canon lines in 01_Characters/VESTIGE.md.)
  • Whisper economy: small prices first (dealer pricing), WILL-gated refusal, escalation per run. Every offer logged (Q) — the log is admissible evidence to the player that the System keeps score.
  • Lie-glitch rendering: text stutter effect in VestigeTerminal + truhound bark. The game tells the truth about lying.

8 Run Modules

8.1 RunBase Class

  • Lifecycle: compose(seed) → breach → zones[3 procedural + 1 story] → twist (VESTIGE) → boss → bind/banish → extract-or-push (Red Door) → settle (loot/tithe/clocks).
  • Seeded RNG per run (replayable dailies + debug seeds). Red Door = double rewards + echo true-death risk.
  • Run length target: 12–25 min. Compose budget §5.5.

8.2 Floor & Test System

  • Floors are data packs: runs/<floor>/floor.json (zones, tables, story room ref, boss ref, test rules, writ reward).
  • Tests are rule overlays (Muster: 200/100/3-days; Sigil: bells + doubling rule). Test logic lives in the pack, adjudicated by RunManager.
  • Cleared floors stay cleared (persistent flags); attempts re-shuffle (roguelike).

8.3 Asset Sharing

  • RunBase owns shared run assets (Husks, corridors, loot tables); packs own specifics (gala strings, bells, sigils). AssetLoader ref-counts across packs.
  • Scenario-generated art lands in runs/<floor>/assets/ with prompt + seed + model recorded (reproducibility; see §10.6).

9 Runs 1–3: Floor Zero, Muster, Sigil Game

9.1 Run 1: Floor Zero — The Unfinished Block (Tutorial)

  • Flow: manifest → routine Grey (6 floors, cutlass-only) → bloom → six-seconds choice → deal → first BIND → flat scan.
  • Teaches: carrying loop, choice theme, death sting (first revive eats father's face), deal hook.
  • Scripted loss, real choice: the team dies regardless; Lark-vs-cores is the player's.
  • Rewards: cutlass, level curve unlocked, Bram. Audio: generator hum → dead air → heartbeat + drum.

9.2 Run 2: The Muster (Survival)

  • Flow: forged paper → 200Scatter → 3-day maze-ward → choke tolls → 100th-writ crush → Voss's pen stops.
  • Mechanics: writ economy, rearrangement navigation, power discipline scoring (optimal plays logged; using them advances Table clock faster — the game prices winning).
  • Rewards: ascent writ (Act 2 key), Subject Seven opens (Table 2/8). Visuals: copied-wrong ward, moving doors, crush lighting.

9.3 Run 3: The Sigil Game (Betrayal)

  • Flow: gala doors → bell 1 (halve) → between-bells offer → bell 2 (shuffle, 40s loss) → bell 3 (dead count double, godhood-seconds, rematch) → paper.
  • Mechanics: alliance rot timers, forced-betrayal lots, rematch duel (scripted loss → earned win), sieve logging.
  • Rewards: Floor 3 writ, both clocks → 4, Rook's blank form. Audio: bell tuned to the lullaby interval (plant in S2, payoff never explained).

Beauty in signage (gala strings, writ stamps, chalk tallies), horror in bodies (veins, cloth layers, chalk eyes). UI follows the world site: hard borders, offset shadows, terminal mono for VESTIGE.

10.5 Animation Guidelines

  • 4-frame-feel combat readability over realism (telegraphs big, recoveries honest).
  • Characters are iso pixel billboards (PixelSprite: hand-authored maps → canvas textures, NearestFilter, screen-flip; walk anim advances with distance). Geometry primitives are banned for characters.
  • Echoes move wrong on purpose (Bram: shield-first glide; Hush: cut frames).
  • Hushblades: sound cuts first — animate the absence (dust hangs, then parts).
  • Red Second: 3s slowmo, FOV punch, desaturation, heartbeat+drum.

10.6 Scenario Generation Pipeline

  • Models re-discovered per batch (catalogs differ per team) — never hardcode model IDs.
  • Style lock: one seed + prompt-expansion off + reference images of approved art; scenario-consistency pass before any batch acceptance.
  • Every accepted asset records prompt + seed + model in its folder (see §8.3). dry_run=true prices everything first.
  • First art targets: Nullspire at 02:14 (hero), Joss + Rook portraits, Terminus Hold interior.

11.2 Music Structure

  • Core loop: heartbeat (Joss) + talking drum (VESTIGE) — the drum answers the heart, slightly late, like it's learning.
  • Hub: sparse strings + generator hum in the container's key. Gala: warm highlife-adjacent strings that cool by semitones as bells approach.
  • Bosses: drum takes the lead; heart must catch up (player-HP-synced tempo — the music knows you're dying).

11.3 Spatial Audio

  • Howler positional: Mimic lures pan before they show; bell interval locates in 3D (players can navigate Floor 2 by ear).
  • Truhound barks are diegetic UI — mixed above effects, never music-ducked.
